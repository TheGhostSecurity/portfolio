About

My final-year project, SomaCloud, is a browser-based cybersecurity training platform that provisions real Kali Linux sandboxes on remote Docker nodes. The scheduler refuses to over-commit CPU or RAM, the cluster talks over mutual TLS, and every worker is auto-provisioned from the admin UI.

Alongside it I've built a live classroom quiz platform with a real-time WebSocket API, and a local AI agent whose model has no direct filesystem access — every tool call passes a permission policy I designed and covered with tests.

Before that I worked as a penetration tester on institutional systems, and I work through TryHackMe courses and CTFs in my own time.

SomaCloud

Final-Year Project

Cybersecurity Sandbox Platform

A self-hosted training platform that provisions isolated Kali Linux sandboxes on remote Docker nodes, giving students a real terminal in the browser and purpose-built vulnerable services to attack — no local setup required.

What I built

  • 59-lab curriculum across 9 attack phases, each lab bundling theory, walkthroughs, challenge questions, container definitions and flag submission.
  • Multi-node scheduler (select_node) that scores candidate nodes by resource fit and rejects placements that would over-commit CPU, RAM or the port range.
  • Self-hosted CA + mutual TLS between app server and workers, with zero-touch provisioning: registering a host installs Docker, issues a certificate and joins it to the Swarm.
  • Encrypted scriptable backups (SQLite online-backup API, AES-256) so the whole platform restores onto new infrastructure in a single command.
  • Instructor analytics — per-student and cohort charts, activity timelines, flag review and PDF export.
